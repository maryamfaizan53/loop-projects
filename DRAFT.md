# Weekly Team Update

This week the team shipped the revamped onboarding flow to all users after a smooth two-week beta, and early numbers show a nice drop in first-day drop-off. We also tracked down and fixed the memory leak in the background job worker that had been causing periodic restarts, and cleaned up the last of the deprecated v1 API endpoints now that all internal callers have migrated. The design team delivered final mocks for the settings page redesign, and the docs site got a much-needed search overhaul. Looking ahead, next week's focus is a scoped rollout of the new billing dashboard to a small customer cohort, tightening up test coverage on the auth service ahead of the SOC 2 audit, and starting the migration off the old CI runners.
